# Attach

- `tmux attach`, `tmux at`, `tmux a`: Attach preferring the most recently used unattached session
- `<prefix>d`: Detach

# Create

- `:new` / `:new-session`: Create a new session
- `x`, `:kill-session`: Kill current session (note `:kill` does not work and gives an "ambiguous command" error)

- `<prefix>$`: Rename session

# Switch

- `<prefix>L`: Go to last session
- `<prefix>(` / `<prefix>)` : Next / Previous session
- `<prefix>s`: Session tree mode (`<number>` in `tree mode` to switch to session)

# Kill

- `kill-session`: Kill current session
