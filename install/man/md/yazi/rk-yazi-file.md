- `r`: Rename
- `a`: Create a file or directory (append a `/` for directory)

# Select

- `<Space>`: Select hovered file
- `<C-a>`: Select All
- `<C-r>`: Inverse selection
- `<Esc>` / `<C-[>`: Clear selection

# Filenames

- `cc`: Copy absolute path
- `cf`: Copy just filename

# Move, Copy

- `x`: Cut files
- `y`: Copy files
- `p`: Paste files
